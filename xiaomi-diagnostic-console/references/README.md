# Referenční runbook

`C201_E1_PREDANI_FINAL_snapshot.md` je **kopie dokumentu dodaného uživatelem** do tohoto chatu (stav 2026-11-11). Nejde o nový ani schválený deploy skript. Dokument není automaticky spouštěn diagnostickou konzolí. Pro živé nasazení používat aktuální runbook v původním Windows repozitáři a nejprve dokončit nezávislý preflight, včetně offline regrese E1.3/20f.

Součástí ZIPu **není** vlastní zdrojový strom Xiaomi gateway, její `gateway.exe`, `managed-ptz-http-probe.exe` ani reálné tokeny/RTSP capability URL. Ty zůstávají na Windows uživatele.
